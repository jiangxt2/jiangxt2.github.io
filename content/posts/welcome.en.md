This site uses Hugo to generate the blog and Vue with Vite to build interactive web demos. GitHub Actions publishes the combined static output to GitHub Pages.

Articles are written in Markdown. A demo can be a standalone HTML/JavaScript page or a complete Vue application. Both types share the same site navigation while keeping their build boundaries explicit.

Future notes will cover databases, data systems, frontend experiments, and open source projects.
