这个站点使用 Hugo 生成博客页面，使用 Vue 和 Vite 构建可交互的网页 Demo，最终通过 GitHub Actions 自动发布到 GitHub Pages。

文章以 Markdown 保存，网页 Demo 则可以是独立的 HTML/JavaScript 页面，也可以是完整的 Vue 应用。两类内容共用同一个站点和导航，但各自保持清晰的构建边界。
